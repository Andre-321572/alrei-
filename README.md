## 🚀 Démarrage Rapide (Frontend Nuxt 3)

### 1. Installation des dépendances
```bash
npm install
```

### 2. Démarrer le serveur de développement
```bash
npm run dev
```
L'application sera accessible sur `http://localhost:3000`.

### 3. Build de production
```bash
npm run build
```

LearnUp - Vue Nuxt.js Online Courses & Education LMS Template

Introduction

Learnup is a clean, modern, and unique Nuxt.js template featuring a stunning design and distinctive functionalities. It is built with the latest version of Bootstrap, Nuxt.js (v4.x) and Vue JS (v3.x). This template is ideal for educational websites and portals, such as universities, colleges, schools, kindergartens, online courses, blogs, academies, tutoring services, and more. We hope you enjoy using this template, and we kindly ask you to rate us after your experience.

Setup Nuxt

Introduction

We are using npm which allows having complete automation for build flow. Please follow below steps to install and setup all prerequisites:

Prerequisites

Please follow below steps to install and setup all prerequisites:

  • Nodejs

    Make sure to have the Node.js installed & running in your computer. If you already have installed Node on your computer, you can skip this step if your existing node version is greater than 18.

  • Git

    Make sure to have the Git installed globally & running on your computer. If you already have installed git on your computer, you can skip this step.

Installation

To setup the template or theme, follow below-mentioned steps:

  • Install Prerequisites

    Make sure to have all above prerequisites installed & running on your computer

After you finished with the above steps, you can run the following commands into the terminal / command prompt from the root directory of the project to run the project locally or build for production use:

Command Description
npm install This would install all the required dependencies in the node_modules folder.
npm run dev Runs the project locally, starts the development server and watches for any changes in your code. The development server is accessible at http://localhost:3000.
npm run build Generates a /build or dist directory with all the production files.
Note:

After the Build file, if you want to check the preview of the Build folder locally, then follow the steps below.

Command Description
npm run preview

Run this command locally, and preview the dist folder http://localhost:3000.

How to change the Theme primary color in Learnup?

If you change the theme or template color please follow the below step, Please first of all open the _custom.js (path: Learnup_NuxtJs/assets/scss/_custom.scss) find the --bs-primary and replace or changes with color code

like:
--bs-primary: #c71f37; replace only #c71f37 to your color for ex. (#f89d36)

How to change the fonts family in Learnup?

If you want to change your font family then Please first of all open the _custom.scss (path: Learnup_NuxtJs/assets/scss/_custom.scss) and add your font family @import url('https://fonts.googleapis.com/css2?family=Jost:wght@200;300;400;500;600;700;800&display=swap'); Import the @import link from your Google Fonts.

And also add or change to your font family name in,
--body-font-family: 'Jost', sans-serif;
--body-font-family: 'Jost', sans-serif;
